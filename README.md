# PaintR

Planned features:

-[X] zooming
-[X] panning
-[X] image loading
-[X] cursor pixel position readout
-[ ] image saving
-[X] pixel by pixel edits
-[ ] panning/drawing mode switch
-[ ] dragging to draw
-[ ] color picker
-[ ] color palette
-[ ] layers
-[ ] layer enabling
-[ ] layer reordering
-[ ] layer renaming
-[ ] layer blend modes
-[ ] layer opacity
-[ ] selecting
-[ ] expanding selection
-[ ] subtracting selection
-[ ] deleting selected
-[ ] moving selected
-[ ] copying selected
-[ ] pasting
-[ ] rotating
-[ ] canvas resize
-[ ] canvas expand/shrink
